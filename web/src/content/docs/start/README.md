# Start

This section is the front door. Four pages, in order: what Net is and where it fits, a five-minute quickstart that gets a bus running and consuming events, the install guide for every supported language, and how to install the Net Claude skills if you're building with a coding agent.

Read [What is Net?](./what-is-net) first if you're new to the system. Skip straight to the [Quickstart](./quickstart) if you've already heard the pitch and want to see code. The [Install](./install) page covers the package names and per-language setup if you need to wire up a non-Rust binding. [Claude Skills](./claude-skills) sets up the standing reference an agent loads while writing Net code.
